## Projects

### 🔥 [ElevateBox AI Voice Agent](https://github.com/RojanFrancis/elevatebox-agent)
> Outbound AI sales agent — calls leads, classifies HOT/WARM/COLD mid-call via Gemini, fires WhatsApp on intent before the call ends, schedules callbacks from natural speech ("call me Thursday morning" → slot booked). Full webhook pipeline runs async in under 2 seconds.
>
> `Java 21` `Spring Boot 3.3` `Vapi` `Twilio` `GPT-4.1` `Gemini Flash` `Cartesia` `Soniox` `Meta WhatsApp API`

### 💳 [Event-Sourced Payment Ledger](https://github.com/RojanFrancis/event-sourced-ledger)
> Fintech-grade payment backend — event sourcing + double-entry bookkeeping (same pattern as Razorpay/Juspay). Balances derived by replaying immutable ledger events. Extended with AI Finance Controller using Gemini Flash for natural language queries over transaction data.
>
> `Java 21` `Spring Boot` `MySQL` `React` `JWT` `Docker`
